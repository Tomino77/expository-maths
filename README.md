# expository-maths
Collection of notes about mathematics that interest me. Typical topics I like researching about are group theory, topology, geometry, and knot theory.
Intended to be scripts to be turned into YouTube videos.

Rubik's Cube Essay (The Rubik's Cube Group) - A script for explaining where the idea that the Rubik's cube is associated with maths comes from. From there, we look at how we can use the mathematical properties of the Rubik's cube to create a generalised solution for the puzzle

Topology Project (Topology from the Group Up) - A journey as to where topology comes from as a research area of mathematics, starting from basic mathematical knowledge, motivating definitions of continuity, and eventually defining homeomorphisms.
